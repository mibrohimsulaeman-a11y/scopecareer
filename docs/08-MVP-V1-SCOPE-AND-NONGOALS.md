# ScopeCareer — MVP / V1 Scope and Non-Goals

Status: Working release scope
Last updated: 2026-08-21

## 1. V1 thesis

V1 should prove four product loops:

1. **Better Opportunity Selection** — identify opportunities the executive genuinely considers worth attention.
2. **Better Pursuit Decisions** — distinguish strong fit from strong career move.
3. **Better Access** — identify stronger routes than reflexive direct application.
4. **Better Executive Preparation** — turn trusted evidence into stronger positioning and selection preparation.

## 2. V1 product line

V1 is candidate-side only:

**Personal Executive Career Intelligence + Candidate MCP + Web/PWA/Browser Capture**

It is not yet a recruiter marketplace/talent platform.

## 3. Foundation scope

- Authentication/account
- Career Data Vault baseline
- Career Evidence Graph
- Resume/CV import
- Employment history
- Leadership mandates
- Achievements/scope facts
- Claim provenance
- Evidence status
- Interpretation status
- Usage permission
- Career Intent
- Basic privacy/sensitivity controls

## 4. Market and opportunity scope

- Target companies
- Watchlist
- Basic company intelligence
- Public opportunity ingestion through legitimate sources
- Manual/confidential opportunity creation
- Browser capture
- Opportunity normalization
- Role-mandate extraction
- Opportunity research
- Opportunity Trust
- Opportunity information state
- Fit Intelligence
- Opportunity Quality
- Transition Intelligence
- Pursuit Recommendation

## 5. Access Lite scope

- Person
- Recruiter/Search Consultant
- Search Firm
- Relationship
- Interaction history
- Access routes
- Access Plan
- Introduction/referral tracking
- Follow-up reminders

Do not build a LinkedIn-style social graph.

## 6. Opportunity execution scope

- Opportunity Workspace
- Disposition: Pass / Watch / Explore / Pursue / Priority
- Executive Positioning Brief
- Resume Variant
- Resume versioning/diff/evidence link
- Executive Narrative baseline
- Selection-process map
- Stakeholder preparation
- Interview/selection preparation
- Text debrief; voice debrief if practical in V1 surface
- Follow-up tracking
- Communication timeline baseline
- Application/selection pipeline
- Offer capture
- Outcome

## 7. Intelligence scope

- Daily attention shortlist
- Career strategy analytics baseline
- sample-size/confidence-aware signals
- basic strategy hypotheses/experiments

## 8. Agent access scope

- Candidate MCP gateway
- read-oriented tools/resources
- selected internal state mutations when host supports them
- MCP rich UI optional where host supports it
- useful fallback for read/fetch-only hosts
- audit and policy enforcement

## 9. Surface scope

- desktop-first responsive Web
- excellent mobile Web/PWA
- browser capture/extension capability
- Candidate MCP

Native iOS/Android is post-validation unless evidence changes.

## 10. V1 non-goals

- mass automatic application;
- autonomous recruiter communication;
- application submission automation by default;
- full social-network graph;
- relationship scraping without explicit compliant basis;
- recruiter marketplace;
- employer candidate ranking;
- corporate Recruiter MCP;
- Hiring Manager MCP;
- Talent Sourcer MCP;
- full native mobile apps;
- AI voice mock interviewer;
- automated negotiation;
- full compensation benchmarking;
- personal-brand content engine;
- community/alumni network;
- coach marketplace;
- predictive labor-market system;
- dozens of autonomous agents.

## 11. V1.1 / V1.x candidates

- delegated Coach access;
- Coach MCP;
- richer voice debrief;
- calendar/email integration;
- deeper relationship reminders;
- advanced market watches;
- enhanced compensation/offer comparison;
- native companion if usage supports it.

## 12. Separate future product line

Talent Intelligence Platform:

- Corporate Recruiter
- Executive Search Consultant
- Talent Sourcer
- Hiring Manager

This requires separate product, privacy, regulatory, and authority review.

## 13. Scope-cut test

A feature should be in V1 only if it materially strengthens at least one of:

- evidence quality;
- opportunity selection;
- pursuit decision;
- access route;
- executive positioning;
- selection progression;
- trustworthy career learning.

If it primarily increases breadth, automation spectacle, marketplace complexity, or vanity dashboarding, defer it.
