Core ideas

  • Capability → Object → State → Action → Policy → Evidence — one canonical chain across web, PWA, extension, MCP, and AI.
  • No generic opportunity status: disposition, search state, selection state, and priority stay orthogonal.
  • Epistemic honesty: provenance and evidence status are never silently upgraded; assessments are versioned snapshots.
  • The UI is a projection; authorization lives server-side; AI holds zero commit authority over state or external effects.
